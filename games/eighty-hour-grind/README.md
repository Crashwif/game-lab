# 80-Hour Grind

**Stack impossible graveyard shifts before your eyelids slam shut**

A sleepy security guard juggles flashing monitors, thermos refills, and second jobs while the shift clock ticks wildly. Cash out early to clock out clean with your overtime pay intact. Crash and collapse face-first onto the keyboard, triggering every emergency alarm in the building.

## Viral Inspiration

Inspired by trending cultural moment: *Security guard working 80 hours a week challenges Kevin O'Leary on grinding harder* ([source](https://x.com/MarioNawfal/status/2122125922367385643)).

## Running locally

Run `npm run preview -- eighty-hour-grind` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
