# Mega Merger

**Weld a Falcon Heavy directly onto a Cybertruck to bypass regulatory audit**

Duct tape electric pickups to interplanetary boosters as the corporate valuation surges toward infinity. Cashing out signs the golden parachute and parachutes safely into a private lagoon. Crashing sparks a catastrophic SEC audit that snaps the merger in half with a galactic pop.

## Viral Inspiration

Inspired by trending cultural moment: *Elon Musk aims to merge Tesla and SpaceX into a $3.7T mega-conglomerate* ([source](https://x.com/unusual_whales/status/2113213019924951289)).

## Running locally

Run `npm run preview -- mega-merger` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
