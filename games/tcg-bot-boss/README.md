# TCG Bot Boss

**Beat the 97 percent win-rate neural network before it steals your deck**

Watch the glowing cybernetic trading bot evolve from rookie scrapper into an omniscient neon deity as multiplier rises. Cash out before its infinite turn plays every combo card on the felt table. If you crash, the bot plays an illegal 99-card exodia finisher that incinerates your hand.

## Viral Inspiration

Inspired by trending cultural moment: *Self-taught Cyberpunk TCG bot wins 97% of games, gets promoted to permanent final boss* ([source](https://x.com/Dexerto/status/2122495113611956272)).

## Running locally

Run `npm run preview -- tcg-bot-boss` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
