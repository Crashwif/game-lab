# Chonk Hawk

**Waddle down the coop buffet before gravity reclaims your raptor wings**

An outrageously plump hawk attempts to lift off from an all-you-can-eat chicken ranch as the multiplier climbs. Cashing out triggers a clumsy glide into a fluffy hay cart with a drumstick intact. Crashing sends the heavyweight bird thudding into the mud with an exhausted burp and flying feathers.

## Viral Inspiration

Inspired by trending cultural moment: *Hawk diagnosed as too fat to fly after bingeing on free-range chickens* ([source](https://x.com/Dexerto/status/2118372818333180048)).

## Running locally

Run `npm run preview -- chonk-hawk` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
