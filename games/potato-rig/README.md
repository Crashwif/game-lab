# Potato Rig RPG

**Overclock your grease-drenched spud rig to run the fast food fantasy RPG**

A spud PC wired into an industrial fry vat boots up a pixelated fantasy realm while oil temps spike. Cashing out ejects a golden crispy combo basket and cool soft serve before combustion. Crashing causes the fry basket cooling rig to boil over in an explosion of smoking fry grease.

## Viral Inspiration

Inspired by trending cultural moment: *Wendy’s launches a turn-based RPG requiring a potato processor and deep fryer GPU* ([source](https://x.com/Dexerto/status/2115277447692214277)).

## Running locally

Run `npm run preview -- potato-rig` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
