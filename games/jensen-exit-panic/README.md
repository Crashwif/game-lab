# Jensen Exit Panic

**Hang up the iconic leather jacket before the GPU board revolts**

A CEO nervously unzips his legendary black leather coat while server racks flicker and board members sprint across the boardroom. Cash out safely to sprint out the emergency exit with your unvested RSUs into a waiting limo. If it crashes, the pre-market stock plummets ten percent and panic sirens flood the trading floor.

## Viral Inspiration

Inspired by trending cultural moment: *Jensen Huang unexpectedly resigns as Nvidia CEO sparking market chaos* ([source](https://x.com/WatcherGuru/status/2120877606115635699)).

## Running locally

Run `npm run preview -- jensen-exit-panic` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
