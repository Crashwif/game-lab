# Preload Choke

**Download a 300GB patch before your street's router melts into slag**

Watch your home fiber line glow orange as neighborhood bandwidth drains down to dial-up speeds. Cash out to secure the 100% install progress bar on your couch. Crash and your ISP explodes into smoke, dropping you back to 56kbps error 404.

## Viral Inspiration

Inspired by trending cultural moment: *GTA 6 preload causes massive internet throttling across UK broadband networks* ([source](https://x.com/Dexerto/status/2120486949995635120)).

## Running locally

Run `npm run preview -- preload-choke` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
