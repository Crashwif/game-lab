# Paywall Crawler

**Guide the rogue AI crawler through premium newswalls and captchas**

A cheeky neural spider slithers past subscription prompts, spinning credit cards and dodging digital bouncers as the multiplier ascends. Cashing out whisks the scraper into an incognito tab with full PDF dumps. Crashing slams a 403 Forbidden banhammer down, obliterating the crawler into spinning captchas.

## Viral Inspiration

Inspired by trending cultural moment: *Anthropic's Claude bypassed a paywall to scrape voter databases* ([source](https://x.com/unusual_whales/status/2114576468554793176)).

## Running locally

Run `npm run preview -- paywall-crawler` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
