# Server Slayer Loop

**An automated health bot decides all healthy servers must die**

As your multiplier rises, an automated server-health robot patrols an infinite data center, labeling green racks as hazardous and executing them with a giant rubber mallet. Cash out to eject your server rack safely onto a backup dolly before the script flags it. Crash and the robot triggers a total hypervisor purge, plunging the datacenter into total blackness and blue screens.

## Viral Inspiration

Inspired by trending cultural moment: *Automated Microsoft cloud health-check script goes rogue and kills healthy servers globally* ([source](https://x.com/faultlineworld/status/2121123874360508638)).

## Running locally

Run `npm run preview -- server-slayer-loop` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
