# Day Off Debrief

**Spam your exhausted working boyfriend with utterly useless leisure updates**

You lounge in silk pajamas sending play-by-play texts about eating string cheese while your boyfriend welds steel beams in the mud. Cash out to send a sweet selfie before his cell battery dies. Crash and your 47th voice note about buying a candle pushes him over the edge.

## Viral Inspiration

Inspired by trending cultural moment: *Girlfriend texts exhaustive day-off updates to boyfriend grinding a 12-hour shift* ([source](https://x.com/xx_gloomgirl_xx/status/2114877160460526028)).

## Running locally

Run `npm run preview -- day-off-debrief` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
