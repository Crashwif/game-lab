# Chore Strike

**Dodge the $350 cleaning fee chore list before checkout morning arrives**

A exhausted vacationer lounges on the couch while a laminated 14-page chore checklist grows legs and violently demands lawn mowing and gutter scrubbing. Cashing out grabs your carry-on luggage and leaps into an Uber right past the front lawn. Crashing summons an unhinged Superhost who hits you with a 1-star review and a surprise $900 deep-clean bill.

## Viral Inspiration

Inspired by trending cultural moment: *Airbnb bans hosts from requiring guests to do laundry, dishes, and unreasonable checkout chores* ([source](https://x.com/Dexerto/status/2112955939292676436)).

## Running locally

Run `npm run preview -- chore-strike` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
