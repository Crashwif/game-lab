# Couch Savings Hack

**Skip the bar, boot the console, and bank imaginary nightlife savings**

A frugal gamer barricades their living room couch against nightclub invites while stacking imaginary $100 drink tabs saved into a glowing financial freedom fortress. Cashing out locks in the bank balance as our hero eats microwave pizza in peaceful victory. Crashing triggers a doorstep raid of bottle-service VIPs dragging you straight to a $400 cocktail lounge.

## Viral Inspiration

Inspired by trending cultural moment: *Financial guru claims staying home to play video games saves $5,000 in bar tabs* ([source](https://x.com/Dexerto/status/2117243592552939630)).

## Running locally

Run `npm run preview -- couch-savings` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
