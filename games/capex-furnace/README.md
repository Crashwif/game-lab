# Capex Furnace

**Burn billions on server cooling just to serve three-cent search summaries**

Shovel pallets of venture cash straight into screaming GPU racks humming beside a private nuclear generator. Cashing out grabs an enterprise cloud invoice before the fiscal quarter closes. Crashing blows the municipal power grid and prints a zero-cent dividend statement.

## Viral Inspiration

Inspired by trending cultural moment: *Big Tech capex hits $125 billion while AI search revenue yields penny margins* ([source](https://x.com/martinvars/status/2115881608372683059)).

## Running locally

Run `npm run preview -- capex-furnace` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
