# Free Throw Freak

**Wind up the clumsiest shooting form in hoops history**

Watch a goofy shooter bend his knees into a pretzel while winding up an impossible shot. Cash out before the release to cleanly swish the net. If you crash, he shatters the backboard or slips backwards onto the mascot.

## Viral Inspiration

Inspired by trending cultural moment: *Bizarre chaotic free throw shooting form goes viral across basketball feeds* ([source](https://x.com/carterl0we/status/2117471478535139531)).

## Running locally

Run `npm run preview -- free-throw-freak` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
