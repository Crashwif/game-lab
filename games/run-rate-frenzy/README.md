# Run-Rate Frenzy

**Multiply last month by thirteen and declare yourself liquid before the SEC blinks**

A sleep-deprived founder in a Patagonia vest feverishly rewires an S-1 financial curve as multiplier tokens skyrocket. Cashing out triggers a golden umbrella ejection into a pile of founder seed checks. Crashing slams an 80-page risk factor audit onto the desk that vaporizes the balance sheet.

## Running locally

Run `npm run preview -- run-rate-frenzy` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
