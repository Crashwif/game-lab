# Data Center Pivot

**Rip graphics cards from weeping gamers to feed hungry server racks**

Watch factory conveyor belts reroute every desktop GPU straight into gargantuan corporate AI server racks while desktop gamers sob outside. Cashing out locks in your server rack contract and slips out with a bulk order payout. Crashing triggers a global thermal cascade where over-stacked data servers blow every fuse in the county.

## Viral Inspiration

Inspired by trending cultural moment: *AMD prioritizes AI data centers over gaming as PC gaming revenue plunges 40%* ([source](https://x.com/Pirat_Nation/status/2119053001814098023)).

## Running locally

Run `npm run preview -- datacenter-pivot` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
