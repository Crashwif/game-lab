# Fridge Bear Raid

**Help a thirsty black bear chug craft brews before the homeowner walks in**

Crack cold ones open as the beer-thirsty beast raids crisper drawers and guzzles six-packs at record speeds. Cash out to slide out the patio glass door undetected with a frosty crate under each arm. Crash and the homeowner catches the drunken beast posing wearing a lampshade.

## Viral Inspiration

Inspired by trending cultural moment: *Bear breaks into Florida home and drinks stolen beer from the fridge* ([source](https://x.com/Dexerto/status/2114009402659213340)).

## Running locally

Run `npm run preview -- fridge-bear-raid` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
