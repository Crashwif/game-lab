# Budget Showdown

**Can forty million in grass physics beat a billion-dollar strip mall**

Two game engines duel on split screens as development spending rockets into orbit. Cashing out locks in your critical review score before marketing expenses eat the profits. Crashing triggers a total studio budget audit that cancels the sequel.

## Viral Inspiration

Inspired by trending cultural moment: *Viral post compares Zelda's lean $40M budget against GTA 6's monstrous $1.5B spend* ([source](https://x.com/RealSinchanDon/status/2120550871058817216)).

## Running locally

Run `npm run preview -- budget-showdown` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
