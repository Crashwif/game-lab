# Tab Apocalypse

**Keep opening browser tabs until your 128GB RAM evaporates**

Watch an overloaded browser window duplicate tabs until the CPU cooling fans scream like jet engines. Cash out in time to save your bookmarks to an external drive. If you crash, the blue screen of death obliterates your unsaved session forever.

## Viral Inspiration

Inspired by trending cultural moment: *Chrome tab hoarder refuses to bookmark pages until 96GB swap space melts motherboard* ([source](https://x.com/dev_horrors/status/1849021893012948011)).

## Running locally

Run `npm run preview -- tab-apocalypse` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
