# ATS Shredder

**Hand your paper resume to the boss before the recruitment AI auto-bins you**

A student desperately hands over a paper CV across a checkout counter while robotic ATS scanners fire rejection laser beams. Cashing out locks in a firm handshake and a store badge before the portal triggers. Crashing delivers a three-minute automated regret email directly to your pocket with buzzing red sirens.

## Viral Inspiration

Inspired by trending cultural moment: *Applicant gets auto-rejected by AI in 3 minutes while talking to manager* ([source](https://x.com/Kingggg__/status/2118063495568666638)).

## Running locally

Run `npm run preview -- ats-shredder` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
