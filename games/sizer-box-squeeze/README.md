# Sizer Box Squeeze

**Cram that swollen duffel into the metal bin before the gate agent notices**

The metal luggage frame groans under the impossible volume of an overstuffed weekender bag filled with bubble wrap and trinkets. Cash out to slide the bag in with a satisfying click and print boarding pass group 1. Crash and the zipper ruptures with acoustic fury, scattering tacky fridge magnets across gate 14.

## Viral Inspiration

Inspired by trending cultural moment: *Passenger tests carry-on sizer cage with a bag packed purely with souvenir snowglobes* ([source](https://x.com/airline_chronicles/status/1894000000000000004)).

## Running locally

Run `npm run preview -- sizer-box-squeeze` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
