# Shed Arsenal

**Out-engineer the Pentagon using duct tape, leaf blowers, and riding mowers**

A suburban dad in safety goggles welds lawn equipment and roman candles onto a rusty riding mower to rival trillion-dollar tech. Cash out to kill the throttle and coast safely into the tool shed before the HOA spots you. Hold too greedily and the nitro-boosted weed-whacker engine detonates, blasting lawn clippings across three subdivisions.

## Viral Inspiration

Inspired by trending cultural moment: *Trillion dollar defense budget countered by backyard redneck DIY contraptions* ([source](https://x.com/MarioNawfal/status/2114373919520198789)).

## Running locally

Run `npm run preview -- shed-arsenal` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
