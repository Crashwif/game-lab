# LeakCord Index

**Scrub your cringe DMs before Google indexes your entire middle school phase**

A panicked gamer frantically clicks 'Delete Message' as Google spiders crawl through embarrassing chat logs while the multiplier surges. Cash out to purge your logs into an encrypted void. Crash and your 2017 anime roleplay hits page one on search results.

## Viral Inspiration

Inspired by trending cultural moment: *Discord makes public chat logs searchable on Google by default* ([source](https://x.com/Dexerto/status/2115142405464699089)).

## Running locally

Run `npm run preview -- leak-cord` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
