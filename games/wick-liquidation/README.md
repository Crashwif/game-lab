# Wick Liquidation

**Dodge the red cascading candles before your long position gets vaporized**

Ride a tiny bull surfing on a monstrous red descending candlestick as liquidation bells chime. Cash out to eject into a golden parachute safely holding bags of stablecoins. If you linger too long, the ultimate cascade margin call hammers down into a total portfolio flatline.

## Viral Inspiration

Inspired by trending cultural moment: *$1 Billion liquidated from crypto markets in 10 minutes as BTC dives under $74K* ([source](https://x.com/WatcherGuru/status/2119551689523179764)).

## Running locally

Run `npm run preview -- wick-liquidation` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
