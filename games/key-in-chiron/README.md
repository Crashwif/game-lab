# Key In Chiron

**Left the keys in a 3-million-dollar hypercar again**

A CEO casually parks his multi-million hypercar with the keys dangling in the ignition as shady opportunists slowly creep out of the bushes. Cashing out locks the doors with a chirping alarm and speeds off into the sunset. Crashing lets a masked joyrider smash the pedal and blast away in a cloud of burnt rubber.

## Viral Inspiration

Inspired by trending cultural moment: *Bugatti CEO Mate Rimac admits $3M hypercar stolen because he left keys inside* ([source](https://x.com/Dexerto/status/2116485535543820583)).

## Running locally

Run `npm run preview -- key-in-chiron` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
