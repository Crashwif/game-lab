# Buffet Bus Blitz

**Smash Golden Corral with the boys before kickoff**

A crowded college team charter bus stacks endless plates from Buc-ee's and buffet troughs while tearing down the highway. Cashing out pulls into stadium parking perfectly nourished for game day. Crashing triggers catastrophic food coma lethargy as the bus tilts into a ditch.

## Viral Inspiration

Inspired by trending cultural moment: *Brent Venables suggests college teams bus 8 hours and smash Golden Corral to bond* ([source](https://x.com/JoshMCallaway/status/2122104695061684460)).

## Running locally

Run `npm run preview -- buffet-bus-blitz` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
