# Doctor Yellow Rush

**Full-speed track inspection with zero passengers and hairline precision**

Ride the canary-yellow ghost train firing laser sensors down high-speed rails as commuter trains watch in awe. Cashing out triggers a clean track signoff and lucky platform wave. Crashing derails into a comedy laser light show as sparks fly across Tokyo Station.

## Viral Inspiration

Inspired by trending cultural moment: *Japan's legendary Doctor Yellow train blasts tracks with diagnostic lasers at 168 mph* ([source](https://x.com/japan_nobunaga/status/2118400452626678082)).

## Running locally

Run `npm run preview -- yellow-laser-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
