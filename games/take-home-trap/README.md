# Take-Home Trap

**Run the shady take-home coding assignment without handing over the vault keys**

A sleep-deprived dev installs an innocent Python coding challenge on their company laptop as suspicious terminal logs stack up. Cash out to shut the laptop lid, revoke local repo permissions, and walk away clean. Crashing triggers automated container deploys that dump company treasury logs straight to pastebin.

## Viral Inspiration

Inspired by trending cultural moment: *Binance postmortem details a $6.34B heist triggered by an engineer running a fake job take-home test* ([source](https://x.com/cyber_razz/status/2117719421317771436)).

## Running locally

Run `npm run preview -- take-home-trap` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
