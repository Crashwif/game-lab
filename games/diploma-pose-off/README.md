# Diploma Pose Off

**Hold ridiculous commencement poses without tumbling off the stage**

Strike increasingly unhinged victory poses as the dean hands over your degree and joins the dance. Cash out early to strut offstage with your rolled parchment and cap intact. Crash and you faceplant off the podium into the brass band's tuba section.

## Viral Inspiration

Inspired by trending cultural moment: *Graduating students strike hilarious poses across the stage while the principal joins in* ([source](https://x.com/HumanityChad/status/2120861016905142288)).

## Running locally

Run `npm run preview -- diploma-pose-off` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
