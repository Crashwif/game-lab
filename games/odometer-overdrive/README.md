# Odometer Overdrive

**Can your rental hatchback break the sound barrier before the desk clerk notices**

You drive a rented compact car whose broken odometer spins faster and faster while billing receipt ticker-tape flies out the exhaust. Cash out to slide cleanly into the airport return lane with a zero-mile dispute form. If you crash, the dashboard erupts in smoke as an infuriated Hertz agent slams you with an astronomical invoice.

## Viral Inspiration

Inspired by trending cultural moment: *Rental company bills driver $4,300 for claiming he drove 18,000 miles in one week* ([source](https://x.com/Dexerto/status/2112853966299996349)).

## Running locally

Run `npm run preview -- odometer-overdrive` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
