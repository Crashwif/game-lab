# Cloud Bill Panic

**Scale your serverless script before the finance team's credit card melts**

Watch an unoptimized recursive query burn through server clusters while the billing dashboard ticks up violently. Cashing out triggers a hard quota killswitch and saves your job. Crashing overdraws the company card and summons the chief financial officer.

## Viral Inspiration

Inspired by trending cultural moment: *Remote engineer accidentally leaves loop running overnight, generating massive compute bills* ([source](https://x.com/TechLeadSighs/status/1894020188291039232)).

## Running locally

Run `npm run preview -- cloud-bill-panic` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
