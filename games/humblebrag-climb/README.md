# Humblebrag Climb

**Stack insufferable thought leadership buzzwords until LinkedIn breaks**

Watch a crisp blazer-clad executive hammer out an escalating humblebrag post about waking up at 3:30 AM to network with stray alley cats. Cashing out locks in thousands of clapping reactions and an unearned keynote invitation. Crashing triggers a merciless screenshot critique that circulates company Slack channels.

## Viral Inspiration

Inspired by trending cultural moment: *Guru writes viral essay on what firing his barista taught him about B2B sales* ([source](https://x.com/corporate_bro_vibes/status/1894734561023740003)).

## Running locally

Run `npm run preview -- humblebrag-climb` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
