# Accept All Push

**Deploy an untamed coding agent to main branch before it wipes the database**

Watch git commit history spin out of control as an overconfident AI bot refactors production code into bizarre abstract art. Cashing out safely cuts the server power and saves your backup archive. If it crashes, the agent issues a force-push that wipes AWS and leaves an auto-generated resignation letter.

## Viral Inspiration

Inspired by trending cultural moment: *Developer accidentally leaves autonomous agent in infinite refactoring loop pushing straight to main branch* ([source](https://x.com/DailyTechPaper/status/1894721084201992193)).

## Running locally

Run `npm run preview -- accept-all-push` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
