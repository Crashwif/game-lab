# Bridal Clutch

**Clutch a 1v1 against your fiancée or remain permanently single at the altar**

Sweat in your rented tuxedo as bridesmaids set up smoke grenades and flashbangs down the aisle. Cash out early to secure the ring and escape on a golf cart. Crash out when your bride executes a 360 noscope headshot while the priest yells GG.

## Viral Inspiration

Inspired by trending cultural moment: *Groom forced to defeat bride in Valorant match before bridesmaids allow the wedding to proceed* ([source](https://x.com/Dexerto/status/2117659447199695233)).

## Running locally

Run `npm run preview -- bridal-clutch` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
