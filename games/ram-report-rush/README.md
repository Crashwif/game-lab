# RAM Report Rush

**Spam Sam Altman's inbox with real-time graphs of every unused gigabyte**

A terminal script fires automated diagnostic emails directly to the CEO inbox detailing criminal amounts of idle DDR5 memory. As the multiplier climbs, the email dispatch volume turns into a crushing denial-of-service avalanche of browser tabs. Cashing out submits an unsubscribe link in the nick of time, while crashing triggers an inbox bounceback that bricked your motherboard.

## Viral Inspiration

Inspired by trending cultural moment: *Dev writes a script emailing Sam Altman daily updates on his unused RAM* ([source](https://x.com/Dexerto/status/2119456205923832312)).

## Running locally

Run `npm run preview -- ram-report-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
