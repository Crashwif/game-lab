# Badge Swipe Blitz

**Swipe your badge at the turnstile before HR catches you working from home**

Sprint past automated security turnstiles while dodging clipboard-wielding HR auditors. Cashing out beeps green with an authorized scan and slips out to a coffee shop. Crashing triggers a red klaxon lockdown as the gate slams shut on your jacket!

## Viral Inspiration

Inspired by trending cultural moment: *Tech company installs automated turnstile badge scanners to enforce 3-day RTO mandate* ([source](https://x.com/CorporateGhost/status/1894720184918231041)).

## Running locally

Run `npm run preview -- badge-swipe-blitz` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
