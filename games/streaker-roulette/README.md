# Streaker Roulette

**Stack chips fast before casino security throws you a bath towel**

You sit unclothed at high roller tables stacking stacks of chips while bouncers whisper furiously into earpieces. Cash out to slip into a VIP bathrobe and ride an escalator into the sunset. Crash and get bundled up in a giant velvet tablecloth and hurled into the valet fountain.

## Viral Inspiration

Inspired by trending cultural moment: *Gambler complains about getting kicked out of casino for winning too much while naked* ([source](https://x.com/raccoonoffender/status/2121762810417836276)).

## Running locally

Run `npm run preview -- streaker-roulette` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
