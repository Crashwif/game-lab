# Agent Harness Rush

**Stack automated worker agents before your junior desk gets deleted**

A sweaty junior corporate analyst straps on neural harnesses while swarms of bot agents churn out slides and memos. Cash out in time to grab senior partner tenure with zero actual work done. Stay too long and an autonomous loop recurses infinitely, deleting your desk and badge from existence.

## Viral Inspiration

Inspired by trending cultural moment: *Anthropic CEO warns AI eliminates half of entry-level jobs unless you build an agent harness* ([source](https://x.com/0xSanabi/status/2119106909919674598)).

## Running locally

Run `npm run preview -- agent-harness-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
