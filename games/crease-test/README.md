# Crease Test

**Fold the dual-screen glass until the hinge screams for mercy**

A robotic testing arm violently clamps a glossy folding smartphone open and shut while a livestream viewer counter surges. Cashing out unclips the device with flawless glass intact just in time for an eBay listing. Crashing snaps the hinge completely backward in an explosive spray of dead OLED pixels.

## Viral Inspiration

Inspired by trending cultural moment: *YouTuber folds an iPhone Duo 10,000 times until a noticeable crease appears* ([source](https://x.com/Dexerto/status/2113287715705827791)).

## Running locally

Run `npm run preview -- crease-test` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
