# Pixel Flaps

**Pass off generative couture to snooty magazine editors before pixels blur**

Inspect luxury quilted handbags and designer pumps under high-magnification loupes as the multiplier rises. Cash out to publish the spread and collect the commission before anyone notices the crooked stitching. Crash when the pixel detector pings red, spawning seven-fingered runway disaster graphics across the newsroom.

## Viral Inspiration

Inspired by trending cultural moment: *Vanity Fair editors cluster around desks pixel-peeping fake AI designer handbags and heels* ([source](https://x.com/mjnblack/status/2118359682460823685)).

## Running locally

Run `npm run preview -- pixel-flaps` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
