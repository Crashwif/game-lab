# Poach The Jacket

**Lure the leather-jacket billionaire into your electric rocket startup**

A tech mogul waves preposterous stock option compensation packets at a rival CEO wearing an iconic black leather biker jacket. Multiplier climbs as datacenter racks and neural supercomputers get thrown into the signing bonus package. Cash out to lock in the superstar hire on an executive NDA; crash and the rival CEO buys your entire gigafactory with pocket change.

## Viral Inspiration

Inspired by trending cultural moment: *Elon Musk says it would be an honor to hire Nvidia CEO Jensen Huang* ([source](https://x.com/WatcherGuru/status/2120689323368751233)).

## Running locally

Run `npm run preview -- poach-the-jacket` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
