# Steam Slop Rush

**Flood the Steam store with seven-fingered AI assets before Gaben notices**

A frantic solo dev types prompts at hyperspeed while conveyor belts dump hallucinated textures, six-legged goblins, and robotic voiceovers onto the store page. Cashing out publishes the title into early access and collects bewildered wishlist dollars. Crashing summons Gabe Newell with a giant ban hammer that delists the entire publisher catalog.

## Viral Inspiration

Inspired by trending cultural moment: *50% of all new Steam games now disclose using AI-generated content* ([source](https://x.com/Dexerto/status/2117301155919208769)).

## Running locally

Run `npm run preview -- steam-slop-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
