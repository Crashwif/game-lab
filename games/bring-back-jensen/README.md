# Bring Back Jensen

**Stack the petition signatures before the boardroom locks the glass doors**

Engineers sprint through the tech campus collecting leather jacket signatures as the multiplier mounts. Cashing out submits the petition right under the HR director's nose for instant stock options. Crashing triggers a corporate reorganization memo that turns everyone into middle management.

## Viral Inspiration

Inspired by trending cultural moment: *Nvidia employees launch petition to bring back Jensen Huang as CEO* ([source](https://x.com/WatcherGuru/status/2121124292675203140)).

## Running locally

Run `npm run preview -- bring-back-jensen` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
