# Leather Spy Date

**Trade GPU secrets over candlelit dim sum before the feds breach the booth**

A leather-jacketed tech CEO slips confidential AI wafers under dim sum platters across a moody bistro table. Cash out to scoop the check and slip into the alleyway limousine before the feds kick in the doors. Crash and microphones pop out of the soup dumplings as flashbangs blind the dining room.

## Viral Inspiration

Inspired by trending cultural moment: *Reports claim Nvidia CEO Jensen Huang had a romantic relationship with a foreign operative* ([source](https://x.com/WatcherGuru/status/2118902136096379063)).

## Running locally

Run `npm run preview -- leather-spy-date` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
