# Uber Hostage ID

**Hold a stranger's dropped German ID hostage for escalating ransom euros**

Dangle a lost laminated driver's license out of an Uber backseat window while demanding higher wire transfers from panicking tourists. Cashing out hands the card back smoothly for a fat stack of euros. Crashing triggers a swift German Bundespolizei tackle that smashes the ID into shreds.

## Viral Inspiration

Inspired by trending cultural moment: *NFL wide receiver finds lost ID in Uber and ransoms it on Instagram for 2000 euros* ([source](https://x.com/NFL_DovKleiman/status/2121779465307181372)).

## Running locally

Run `npm run preview -- uber-hostage-id` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
