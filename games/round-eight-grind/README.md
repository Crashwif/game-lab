# Round Eight Grind

**Survive the gauntlet of culture fit chats before HR ghosts you forever**

A job seeker sweats in business-casual attire as interviewers rotate like speed daters across a grid of monitors. Cashing out locks in an official offer letter signed in digital ink. Crashing yields a canned automated rejection email thanking you for your time.

## Viral Inspiration

Inspired by trending cultural moment: *Candidate enters eighth consecutive interview round to design a fictional company roadmap* ([source](https://x.com/tech_hire_pain/status/1894982719283918204)).

## Running locally

Run `npm run preview -- round-eight-grind` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
