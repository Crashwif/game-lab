# Cancel Quest

**Dodge guilt-trip popups and invisible font to cancel your subscription**

Navigate an absurd labyrinth of microscopic gray buttons while an emotional mascot weeps on screen. Cashing out locks in the final confirmed cancellation email with zero hidden fees. Crashing accidentally auto-renews a lifetime family enterprise plan for twenty years.

## Viral Inspiration

Inspired by trending cultural moment: *User documents navigating 14 guilt screens to cancel a 3-dollar gym app* ([source](https://x.com/DarkPatternSurfer/status/1894182901847129841)).

## Running locally

Run `npm run preview -- cancel-quest` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
