# Split Tens Panic

**The ultimate table sin is splitting 20 against a dealer five**

A sweaty gambler in neon sunglasses insists on splitting two face cards while the casino pit boss sweats through his suit. Cash out to scoop two shiny aces and bolt through the valet. Crash and massive security guards tackle the entire table into green-felt confetti.

## Viral Inspiration

Inspired by trending cultural moment: *Blackjack player splits a pair of tens and gets aggressively swarmed by pit bosses* ([source](https://x.com/circusap/status/2120250381066477724)).

## Running locally

Run `npm run preview -- split-tens-panic` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
