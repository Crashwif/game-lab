# TV Licence Raid

**Stream illicit sitcoms before the BBC detector van kicks down your door**

A sweaty streamer hides in the dark watching free web videos while an inspector van creeps up the street. Cashing out closes the curtains and turns off the Wi-Fi to dodge the fine. Crashing means a high-vis inspector smashes through the drywall with a clipboard and a £1,000 penalty notice.

## Viral Inspiration

Inspired by trending cultural moment: *UK considers mandatory £180 TV license for YouTube and Netflix viewers* ([source](https://x.com/Dexerto/status/2112544645422928350)).

## Running locally

Run `npm run preview -- tv-licence-raid` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
