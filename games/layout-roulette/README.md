# Layout Roulette

**Pick between two cursed floorplans before the load-bearing wall snaps**

A sweaty interior designer shifts walls back and forth on a 3D blueprint as the toilet moves into the pantry and the shower wraps around the stove. Cashing out locks the deed on a mildly livable duplex and snaps tape measure in triumph. Crashing collapses the drywall stack into a dusty heap of broken ceramic tiles and open plumbing.

## Viral Inspiration

Inspired by trending cultural moment: *Viral architectural debate rages over cursed interior floorplan blueprints* ([source](https://x.com/NoContextHumans/status/2115383077144862871)).

## Running locally

Run `npm run preview -- layout-roulette` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
