# No AI Bailout

**Beg Capitol Hill for emergency compute credits before the gavel drops**

Guide a panicking tech founder clutching a melted server rack as congressional hearings turn frosty. Cash out in time to escape through the lobby turnstile with remaining seed capital. If you bust, the gavel slams down and an auctioneer sells off your algorithms for scrap metal.

## Viral Inspiration

Inspired by trending cultural moment: *Congress introduces resolution banning federal bailouts for bankrupt AI tech firms* ([source](https://x.com/unusual_whales/status/2115496372824899853)).

## Running locally

Run `npm run preview -- no-ai-bailout` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
