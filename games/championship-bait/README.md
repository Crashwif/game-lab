# Championship Bait

**Claim your fake team rings before HR discovers the accounting error**

Watch an office mailroom clerk load giant diamond championship rings onto fingers as the multiplier climbs. Cashing out locks in your diamond loot and flees down the service elevator. Crashing triggers a frantic audit squad barging in to revoke all the bling with repo clipboards.

## Viral Inspiration

Inspired by trending cultural moment: *Knicks mistakenly sent fake championship ring emails to staff, forced to buy $3.7M in real jewelry* ([source](https://x.com/Dexerto/status/2113722196304523723)).

## Running locally

Run `npm run preview -- championship-bait` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
