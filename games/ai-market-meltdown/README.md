# AI Meltdown

**Stack cooling rigs before $480 billion evaporates into thin vapor**

Server racks glow white-hot as unhinged valuations push cooling fans to max RPM. Cashing out ejects your server unit onto a refrigerated freight dolly. Crashing blows the main breaker into a fountain of fried circuit boards and sparks.

## Viral Inspiration

Inspired by trending cultural moment: *China AI stock bubble bursts, wiping out $480 billion in tech market valuation* ([source](https://x.com/ToonHive/status/2114885830682497411)).

## Running locally

Run `npm run preview -- ai-market-meltdown` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
