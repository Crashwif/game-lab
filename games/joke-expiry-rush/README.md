# Joke Expiry Rush

**Post every last 'we got this before GTA 6' meme before the clock runs out**

A sleep-deprived creator frantically scribbles absurd 'before GTA 6' captions on a smoking whiteboard as the countdown digits flicker red. Cashing out locks in a viral post archive and rolls the credits early. Crashing triggers the midnight launch bell, instantly deprecating every punchline into stale internet museum dust.

## Viral Inspiration

Inspired by trending cultural moment: *Only 10 days left before every 'before GTA 6' joke permanently expires* ([source](https://x.com/linkkling/status/2120300038790537434)).

## Running locally

Run `npm run preview -- joke-expiry-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
