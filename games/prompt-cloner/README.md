# Prompt Cloner

**Rip legendary retro classics in seconds before safety filters terminate you**

Your rogue AI terminal compiles bootleg game assets frame by frame as the multiplier climbs. Cashing out exports a playable build to an untraceable USB drive just in time. Waiting too long triggers an instant corporate banhammer that deletes your terminal in a shower of policy error codes.

## Viral Inspiration

Inspired by trending cultural moment: *Anthropic bans Claude Code from reverse-engineering and cloning existing video games* ([source](https://x.com/Polymarket/status/2116912435281949001)).

## Running locally

Run `npm run preview -- prompt-cloner` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
