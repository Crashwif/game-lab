# SSD Purge

**Sacrifice precious personal files to make room for a 210GB preload**

A desperate gamer frantically deletes childhood photos, taxes, and operating system kernels as the progress bar creeps forward. Cashing out pauses the download and saves your remaining hard drive safely. Crashing triggers a disk write failure that wipes the entire motherboard into smoking slag.

## Viral Inspiration

Inspired by trending cultural moment: *GTA 6 download confirmed at 210GB as gamers face massive storage purges* ([source](https://x.com/TGGonYT/status/2115246837762510895)).

## Running locally

Run `npm run preview -- ssd-purge` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
