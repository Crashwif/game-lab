# Baby Stache

**Skip kindergarten and speedrun an entire midlife crisis from the crib**

A newborn swaddled in nursery fleece rapidly grows an oil-slick handlebar mustache while filling out IRS 1040 tax forms as the multiplier spikes. Cashing out lets him retire early to a golf condo in Florida with his 401k safely rolled over. Crashing triggers a massive colic tantrum that blows his monocle and suspenders clear off.

## Viral Inspiration

Inspired by trending cultural moment: *A newborn baby goes viral for arriving in the world rocking a full adult mustache* ([source](https://x.com/MarioNawfal/status/2113745218667483470)).

## Running locally

Run `npm run preview -- baby-stache` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
