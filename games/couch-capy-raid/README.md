# Couch Capy Raid

**Blend in with the golden retrievers before Dad checks the living room**

A chill capybara trots through the patio sliding door disguised in a collar alongside barking retrievers. As the multiplier spikes, he hops onto the plush velvet sofa, nibbles charcuterie, and switches the TV remote. Cash out to slip behind the ottoman unnoticed, or crash when Dad turns the lights on and screams.

## Viral Inspiration

Inspired by trending cultural moment: *Capybara sneaks into living room alongside pet dogs during a tornado siren* ([source](https://x.com/Rainmaker1973/status/2118840857885626508)).

## Running locally

Run `npm run preview -- couch-capy-raid` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
