# Patch Diff Panic

**Update the server before rogue AI bots reverse engineer the git diff**

A trembling IT administrator tries to drag a massive firmware update bar while swarm algorithms disassemble the release notes in real time. Cashing out slams the server room airlock shut with pristine zero-trust compliance. Crashing lets the autonomous crawler inject a ransom prompt that turns all office monitors into ASCII skull gifs.

## Viral Inspiration

Inspired by trending cultural moment: *Google warns autonomous AI cyber attacks scan updates and exploit flaws instantly* ([source](https://x.com/unusual_whales/status/2122506553047814275)).

## Running locally

Run `npm run preview -- patch-diff-panic` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
