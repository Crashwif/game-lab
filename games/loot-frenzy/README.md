# Loot Frenzy

**Spam claim every skin in the shop before the server hotfix hits**

A sweaty battle royale kid feverishly clicks 'Claim All' as rare skins, banana suits, and neon pickaxes pile to the ceiling. Cash out to glider-dive away with a backpack stuffed with free cosmetic glory. Crash and Epic pushes an emergency patch that confiscates your inventory down to default sweatpants.

## Viral Inspiration

Inspired by trending cultural moment: *Fortnite adds mythical reward unlocking the entire item shop for free* ([source](https://x.com/Dexerto/status/2116870453213991027)).

## Running locally

Run `npm run preview -- loot-frenzy` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
