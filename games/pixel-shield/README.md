# Pixel Shield

**Stack ultra-thin curved screens before incoming drywall debris punches through**

Weld heavier refresh-rate monitors onto your gaming bunker as stray plaster and flying hardware blast across the room. Cash out to slide your warranty replacement into place safely. Crash and the screen matrix crumbles into thousands of burning dead pixels.

## Viral Inspiration

Inspired by trending cultural moment: *Gaming monitor stops a stray projectile and hardware maker vows to honor its heroic sacrifice* ([source](https://x.com/Dexerto/status/2117573503582953496)).

## Running locally

Run `npm run preview -- pixel-shield` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
