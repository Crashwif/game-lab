# Chest RNG Rush

**Crack cursed battle royale chests hunting the fabled 1-in-137,500 pirate token**

A sweaty default skin franticly pries open glowing loot chests amidst closing storm circles and loot drop piles. Cash out early to secure your shiny cosmetic stash and ride the victory glider home. If you greed for the ultra-rare gold doubloon, the chest spawns a rusted common pistol and the storm collapses right onto your skull.

## Viral Inspiration

Inspired by trending cultural moment: *Epic confirms Fortnite Pirate Shop Coin has a 1-in-137,500 spawn chance* ([source](https://x.com/Dexerto/status/2119235450699465124)).

## Running locally

Run `npm run preview -- chest-rng-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
