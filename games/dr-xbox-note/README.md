# Dr Xbox Sick Note

**DJ Khaled prescribes another day off so you can play Vice City in peace**

Escalate your forged medical excuse on an ornate prescription pad while HR calls the clinic to verify. Cashing out faxes the sealed note just in time for you to boot up your console guilt-free. Crashing reveals DJ Khaled yelling 'Another one!' on speakerphone directly to your angry supervisor.

## Viral Inspiration

Inspired by trending cultural moment: *Xbox releases DJ Khaled signed doctor notes to excuse gamers from work for GTA 6 launch* ([source](https://x.com/Dexerto/status/2122366617766040011)).

## Running locally

Run `npm run preview -- dr-xbox-note` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
