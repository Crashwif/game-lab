# Cart Delay

**Ship your digital storefront before the shopping cart takes four years**

A CEO frantically glues metaverse skins and AI code snippets onto an online game launcher while delaying basic e-commerce features. Cashing out lets you purchase a single digital hat through a real functioning checkout basket. Crashing spawns five community notes as the entire launcher uninstalls your desktop wallpaper.

## Viral Inspiration

Inspired by trending cultural moment: *Epic Games CEO faces backlash over metaverse pivots, missing shopping carts, and AI slop* ([source](https://x.com/ScyanYT/status/2116594863034781752)).

## Running locally

Run `npm run preview -- cart-delay` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
