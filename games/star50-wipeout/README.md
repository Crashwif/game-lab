# STAR50 Wipeout

**Ride the artificial hype rocket before the 480-billion vaporizes**

A frantic silicon broker stacks glowing tensor cores while index charts skyrocket into ridiculous heights. Cash out to pack up a golden server rack and slide away in an electric rickshaw. If it crashes, the power grid snaps, leaving piles of burning circuit boards and useless balance sheets.

## Viral Inspiration

Inspired by trending cultural moment: *China's AI bubble bursts wiping out $480 billion as STAR50 tech index plunges* ([source](https://x.com/NewsWire_US/status/2114826581411557674)).

## Running locally

Run `npm run preview -- star50-wipeout` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
