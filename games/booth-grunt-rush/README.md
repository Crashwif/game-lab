# Booth Grunt Rush

**Crank Tom's mic gain before his chaotic grunt explodes the soundboard**

As the multiplier climbs, an impeccably groomed NFL analyst lets out increasingly bizarre involuntary grunts, gasps, and primal squeals directly into the headset. Cashing out drops the studio cough-button just in time for clean commercial transition music. Crashing unleashes an ear-piercing subwoofer belch that detonates all mixing desk meters across prime time television.

## Viral Inspiration

Inspired by trending cultural moment: *Tom Brady's chaotic off-script sound effects in the broadcast booth go viral* ([source](https://x.com/NFLMemes/status/2122149275639664659)).

## Running locally

Run `npm run preview -- booth-grunt-rush` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
