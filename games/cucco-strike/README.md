# Cucco Strike

**Kick the pixel rooster once and prepare to face an avian apocalypse**

A streamer clad in green tunic pokes a tiny harmless farm bird as feathers start to scatter. As the multiplier surges, skyward clouds darken with thousands of shrieking poultry locking in their flight vectors. Cashing out activates a smoke bomb roll into a haycart, while crashing triggers an inescapable pecking vortex that reduces the hero to pixel dust.

## Viral Inspiration

Inspired by trending cultural moment: *IShowSpeed gets wiped out by an angry chicken swarm in Zelda remake* ([source](https://x.com/Dexerto/status/2118714790172356690)).

## Running locally

Run `npm run preview -- cucco-strike` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
