# FAA Floppy Panic

**Keep the 1982 air traffic server alive before the 5.25-inch disk melts**

Guide a glowing green CRT radar terminal as stacked flight blips swarm the airspace and cooling fans scream. Cash out to clear the runway and land your private jet in the nick of time. Crash and the dusty beige mainframe blows a capacitor, grounding every plane in the nation into a comical holding pattern.

## Viral Inspiration

Inspired by trending cultural moment: *FAA nationwide ground stop caused by an overloaded, antiquated air traffic computer system* ([source](https://x.com/WatcherGuru/status/2121417628162105761)).

## Running locally

Run `npm run preview -- faa-floppy-panic` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
