# Overnight GPU

**Ship 300 server racks overnight for fifty bucks before the postal van snaps**

A groaning mail courier attempts to stack a 60-million-dollar AI supercluster into an ordinary delivery hatchback. As the multiplier spikes, miles of glowing fiber-optic cables drag behind and the suspension screams under 9,000 molten server cards. Cash out to sign the delivery clipboard and scurry away, or crash when the fragile parcel explodes into smoking silicon confetti.

## Viral Inspiration

Inspired by trending cultural moment: *IT company lists a 300-rack 9,000 GPU AI cluster on eBay with $50 overnight shipping* ([source](https://x.com/Dexerto/status/2115753065588400427)).

## Running locally

Run `npm run preview -- overnight-gpu` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
