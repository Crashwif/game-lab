# Zuck Exodus

**Flee California before Sacramento garnishes 5% of your sunscreen stockpile**

Steer a solar-powered e-foil loaded with servers, VR goggles, and wagyu cattle away from Silicon Valley as state tax auditors give chase in kayaks. Cash out to hop the Nevada border into a zero-tax bunker. Crash and the Golden Gate bridge tolls snap your paddle while state taxmen impound your hydrofoil.

## Viral Inspiration

Inspired by trending cultural moment: *Mark Zuckerberg considers fleeing California over proposed 5% billionaire tax* ([source](https://x.com/unusual_whales/status/2113018152921821293)).

## Running locally

Run `npm run preview -- zuck-exodus` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
