# Bequeath The Bag

**Hold a catastrophic 2008 penny stock across 16 years of inheritance**

A dusty CRT monitor flickers inside an estate attorney office as forgotten certificates pile up on a desk. Cashing out sells the portfolio just in time for probate taxes and a sentimental family cruise. Crashing triggers a reverse stock split that leaves you inheriting exactly forty-two cents and a laminated certificate.

## Viral Inspiration

Inspired by trending cultural moment: *Son opens late father's 2008 brokerage account to discover he never sold his $41k crash stock* ([source](https://x.com/JSCC2020Lee/status/2121370005438935348)).

## Running locally

Run `npm run preview -- bequeath-the-bag` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
