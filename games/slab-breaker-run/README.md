# Slab Breaker

**Crack the graded slab before the grading purists epoxy it forever**

A rogue preservationist taps a jewel hammer against an ultra-rare graded plastic cartridge case to dump the lost ROM for humanity. Cashing out pops the cartridge free into a card reader while the crowd cheers. Crashing smashes the brittle acrylic and crushes the vintage memory chip into fine dust.

## Viral Inspiration

Inspired by trending cultural moment: *Lost PokePark DS cartridge resurfaces sealed in a PSA slab as fans beg to crack it open* ([source](https://x.com/Dexerto/status/2121633023196315951)).

## Running locally

Run `npm run preview -- slab-breaker-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
