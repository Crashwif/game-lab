# WendyQuest Run

**Grind a 15-hour pixel RPG dungeon just to win a single spicy nugget combo**

Battle greased-up goblin fry cooks as your pixelated party hacks through infinite dungeons of deep-fried loot. Cash out to redeem your dripping cardboard voucher bag before the kitchen closes. If it crashes, the dungeon server resets and drops a soggy ice cream coupon instead.

## Viral Inspiration

Inspired by trending cultural moment: *Wendy's releases a 15-hour RPG where slaying bosses unlocks real fast food* ([source](https://x.com/Dexerto/status/2118297292788621665)).

## Running locally

Run `npm run preview -- wendy-quest-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
