# Vice Unbox Run

**Peel back the plastic wrap before publisher lawyers breach the door**

A sweaty streamer frantically peels layers of bubble wrap off a bootleg Vice City game disc while legal cease-and-desist drones circle outside. Cashing out speeds away in a getaway scooter with the holy grail in hand. Crashing summons SWAT attorneys crashing through the drywall with copyright shredders.

## Viral Inspiration

Inspired by trending cultural moment: *First alleged physical copy of GTA 6 gets unboxed in the wild* ([source](https://x.com/GTA6Intel/status/2120283676064022751)).

## Running locally

Run `npm run preview -- vice-unbox-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
