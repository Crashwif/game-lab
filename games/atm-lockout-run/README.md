# ATM Lockout Run

**Spam the cash dispenser button before the mainframe bluescreens nationwide**

A salaryman jams his cash card into an erratic ATM machine while flashing error codes cascade across bank terminals. Cashing out grabs the dispensed yen stack and sprints down the subway stairs. Crashing freezes the machine as it chews up the card and flashes Out of Service.

## Viral Inspiration

Inspired by trending cultural moment: *128 Japanese credit unions suffer massive outage locking ATM cash withdrawals* ([source](https://x.com/WatcherGuru/status/2118670681261134232)).

## Running locally

Run `npm run preview -- atm-lockout-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
