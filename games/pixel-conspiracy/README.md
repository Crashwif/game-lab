# Pixel Conspiracy

**Squint hard enough at blurry 90s textures and unlock the universe**

A sweaty retro gamer runs enhancement algorithms on 4 blurry fountain pixels. Cash out to publish a breathless 3-hour YouTube documentary. Crash and realize the sacred ancient glyphs literally translate to a placeholder dev joke.

## Viral Inspiration

Inspired by trending cultural moment: *Super Mario 64 blurry fountain text mystery supposedly deciphered after 30 years* ([source](https://x.com/Dexerto/status/2113073062639710231)).

## Running locally

Run `npm run preview -- pixel-conspiracy` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
