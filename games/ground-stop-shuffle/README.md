# Ground Stop Shuffle

**Keep commuter planes rolling down runways while air traffic monitors freeze**

Guide a taxiing airliner through crowded tarmac gates while departure monitors turn into giant blue screens of death. Cash out to park at the gate before the shutdown and snag the last airport pretzel. Crash and a blaring red terminal alert freezes every luggage tug and sends departure flight boards spinning into static.

## Viral Inspiration

Inspired by trending cultural moment: *FAA nationwide aviation system failure strands 1.5 million holiday passengers* ([source](https://x.com/MarioNawfal/status/2121543672894247161)).

## Running locally

Run `npm run preview -- ground-stop-shuffle` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
