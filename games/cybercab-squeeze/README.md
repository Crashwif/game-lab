# Cybercab Squeeze

**Strip down the assembly line to build liquid silver robotaxis fast**

Robotic arms weld chassis faster and spray gleaming liquid silver enamel as the multiplier revs up. Cashing out puts your sleek driverless cab on open highway with paid fares. Crashing sparks a total factory short circuit that traps engineers in stainless steel scrap heaps.

## Viral Inspiration

Inspired by trending cultural moment: *Elon reveals liquid silver 40kWh Cybercabs while reallocating Cybertruck factory staff* ([source](https://x.com/elonmusk/status/2119152839813456261)).

## Running locally

Run `npm run preview -- cybercab-squeeze` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
