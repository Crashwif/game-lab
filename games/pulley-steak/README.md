# Pulley Steak

**Lower the sizzling ribeye out the 4th floor window without dropping it**

A greasy cast-iron skillet swings precariously down a rickety clothesline rig across busy Manhattan traffic. Cash out in time to drop the steak cleanly into a hungry hipster's tote bag. Crash and the clothesline snaps, bombarding a police cruiser with hot garlic butter.

## Viral Inspiration

Inspired by trending cultural moment: *NYC apartment restaurant 'Some Guy's House' serves steaks out a window on a pulley* ([source](https://x.com/Dexerto/status/2117451921703207229)).

## Running locally

Run `npm run preview -- pulley-steak` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
