# Data Lumberjack

**Clear boreal pine groves to feed AI server clusters before regulators wake up**

Raze hundreds of square miles of Scandinavian woodland with robotic harvesters as your compute cluster grows exponentially. Cash out to pocket clean tech carbon credits and build a manicured server fortress. Crash when environmental inspectors blockade the logging fleet with furious reindeer.

## Viral Inspiration

Inspired by trending cultural moment: *Tech giant halts Finland AI data center build after flattening 250,000 pine trees* ([source](https://x.com/CollinRugg/status/2113712384590348513)).

## Running locally

Run `npm run preview -- data-lumberjack` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
