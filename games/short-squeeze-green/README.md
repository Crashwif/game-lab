# Short Squeeze Green

**Ride the monster green candle elevator as leveraged short sellers get vaporized**

A towering pixelated green candlestick blasts through ceiling tiles like a missile, sending frantic bear avatars tumbling into margin call flames. As the multiplier spikes, liquidation sirens howl and shorts scramble to delete their prediction tweets. Cash out to lock in the green candle pump and drink champagne, or crash when a giant red wick snuffs out the ascent.

## Viral Inspiration

Inspired by trending cultural moment: *Bitcoin turns green and reclaims 65k liquidating over 130 million dollars of shorts* ([source](https://x.com/WatcherGuru/status/2121802194517450941)).

## Running locally

Run `npm run preview -- short-squeeze-green` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
