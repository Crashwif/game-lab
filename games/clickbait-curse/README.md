# Clickbait Curse

**Scrub the timeline before the algorithm catches you mid-sneeze**

A sweaty creator fights to maintain a hyper-edited shocked face thumbnail while YouTube's random frame selector rolls through hideous unflattering pauses. Cash out to publish a 10/10 viral banger and bank the viewcount. Crash out and the algorithm locks in a cursed double-chin mid-blink frame forever.

## Viral Inspiration

Inspired by trending cultural moment: *YouTuber suggests replacing custom clickbait thumbnails with random video frames* ([source](https://x.com/Dexerto/status/2115813444083490867)).

## Running locally

Run `npm run preview -- clickbait-curse` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
