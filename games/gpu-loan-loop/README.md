# GPU Loan Loop

**Lend them cash so they can buy your chips to fund your cash**

A frantic corporate executive shuffles IOUs around a revolving conveyor belt that pumps GPUs directly into a hollow cardboard data center. Cash out to wire the vendor check into a discrete offshore vault before the credit audits hit. If you hold too long, the circular balance sheet collapses under its own fictitious guarantees.

## Viral Inspiration

Inspired by trending cultural moment: *Nvidia faces scrutiny over $530B circular debt loop financing customers to buy its own chips* ([source](https://x.com/BullTheoryio/status/2121166572647772461)).

## Running locally

Run `npm run preview -- gpu-loan-loop` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
