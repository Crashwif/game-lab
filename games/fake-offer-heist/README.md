# Fake Offer Heist

**Download the recruiter's coding test before IT revokes your badge**

A desperate remote engineer sits on a video call downloading dubious interview repos while cash drains from the server behind him. Cash out to close the laptop and pocket your signing bonus before security arrives. Crash and the terminal goes full ransomware skull as multisig locks you in the server closet.

## Viral Inspiration

Inspired by trending cultural moment: *North Korean hackers steal $6.3B from Binance using a fake job interview and test code* ([source](https://x.com/aakashgupta/status/2117890593041137757)).

## Running locally

Run `npm run preview -- fake-offer-heist` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
