# Claude Rip Run

**Prompt faster before the corporate copyright strike nukes the terminal**

A sleep-deprived indie dev feeds forbidden prompts into Claude to bootleg retro classics before legal ninjas swarm the room. Cashing out exports a legally distinct open-source demo to itch.io under an alias. Crashing brings down a gigantic red DMCA cease-and-desist gavel that smashes the monitor into smoking pixel dust.

## Viral Inspiration

Inspired by trending cultural moment: *Anthropic bans Claude Code from recreating existing video games to avoid DMCA strikes* ([source](https://x.com/Dexerto/status/2116885499717599656)).

## Running locally

Run `npm run preview -- claude-rip-run` from the clone root. The backend supplies committed outcomes; credits have no monetary value.
